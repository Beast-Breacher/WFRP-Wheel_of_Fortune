# WFRP4e — Колесо Судьбы

Репозиторий: https://github.com/Beast-Breacher/WFRP-Wheel_of_Fortune

Адрес манифеста для Foundry (после публикации первого выпуска):

```text
https://github.com/Beast-Breacher/WFRP-Wheel_of_Fortune/releases/latest/download/module.json
```

Дополнительный модуль для **Foundry VTT 13–14** и системы **WFRP4e 9.6.0+**, включая ветку 9.6.x и версию 10.1.2. Непосредственно проверенная сборка Foundry: 14.369 с WFRP4e 10.1.2. Совместимость с 9.6.x проверена по исходной схеме биографии и контрактам API; отдельный игровой мир на Foundry 13/WFRP4e 9.6.x пока не запускался. Интерфейс и все генерируемые имена — на русском.

## Возможности

- Колесо Судьбы: выбор прежней карьеры, матрица переходов и генерация карьеры родственника с фильтрацией по народу.
- Реестр 144 карьер с источниками, народами и ограничениями Высших эльфов.
- Неофициальный пакет: рождение, знак, внешность, мотивация, рок, место рождения, семья, супруг/дети, тайна; полная или отдельная генерация.
- Бремя детей Азуриана: флажок для мужчины — Высшего эльфа. Только при 1–5 на d100 добавляется художественный текст и результат броска; неудачные проверки не выводятся.
- Имена людей, гномов, полуросликов, карликов, Высших и Лесных эльфов с учётом пола. Люди: имперцы, тилийцы, эсталийцы и кислевиты.
- Погода на месяц: 30 климатов, месяцы Имперского календаря по 32/33 дня, восьмидневная неделя, дневная/ночная температура в °C, осадки, ветер и опасные условия.
- Копирование результата, отправка в чат с выбранной видимостью, журнал «Погода» со страницами по месяцу и году, отдельные записи остальных генераторов и добавление предыстории в биографию принадлежащего пользователю персонажа.

Изображений и музыки нет. Модуль работает локально на JavaScript, без Python, EXE, загрузки Excel, CDN, библиотек и сетевых сервисов. Таблицы входят в пакет как редактируемые JavaScript-данные. Официальный пакет `wfrp4e-core` может быть включён в мире, но не является дополнительной технической зависимостью модуля.

## Локальная установка

1. Поместите содержимое папки проекта в `Data/modules/wfrp4e-wheel-of-destiny/`. Внутри этой папки должен лежать `module.json`, а не ещё одна вложенная папка проекта.
2. Перезапустите Foundry, если модуль был добавлен во время её работы.
3. Откройте тестовый мир WFRP4e → Настройки игры → Управление модулями → включите **WFRP4e — Колесо Судьбы** → сохраните изменения.
4. Откройте Настройку параметров → Параметры модуля → **Генераторы WFRP4e**. Также в каталоге персонажей добавляется кнопка «Колесо Судьбы».
5. Для панели быстрого доступа создайте макрос типа Script:

```js
game.modules.get("wfrp4e-wheel-of-destiny").api.open();
```

Если кнопки в каталоге нет из-за другой надстройки интерфейса, пункт настроек и макрос остаются доступными.

## Работа с персонажами и результатами

Кнопка «Добавить в биографию» открывается после генерации в Неофициальном пакете. Выберите персонажа, подтвердите добавление. Модуль дописывает текст в `system.details.biography.value`; имя, карьеры, характеристики, таланты и предметы персонажа не меняются. Механические эффекты неофициального пакета выводятся для решения ведущим.

Региональные ограничения — предупреждения: карьеру не исключаем из списка. «Воин тени» доступен только в Нагарите, «Докер» — только морским эльфам, «Мастер меча» недоступен морским эльфам. Отдельного выбора провинции для автоматической фильтрации нет.

Год рождения считается от мирового параметра «Текущий год Имперского календаря» (2512 по умолчанию). Шанс проклятия равен 5%. По умолчанию чат отправляется себе и ведущему; публичную отправку нужно выбрать явно. Создание записи журнала доступно ведущему. Доступ игроков к генераторам можно отключить в настройках модуля.

В генераторе имён человека выберите культуру. В Неофициальном пакете культура по умолчанию определяется по фактически выпавшему месту рождения: Тилия, Эсталия и Кислев используют свои наборы; остальные человеческие регионы — имперский. Можно выбрать культуру вручную, например для тилийца, родившегося в Рейкланде. Для эльфов, гномов и остальных народов сохраняются собственные наборы. Стабильные ключи API `Dwarf` и `Gnome` означают соответственно «Гном» и «Карлик».

Год погоды задаётся на вкладке и первоначально берётся из мирового параметра года. Кнопка «Добавить в журнал „Погода“» создаёт приватный журнал «Погода», если его ещё нет, а затем добавляет страницы вида «Ярдрунг 2512 И.К.» в существующий журнал с этим именем. Существующие страницы и права доступа сохраняются; повторное сохранение добавляет ещё одну страницу. Месяц и год относятся к сгенерированному отчёту: после изменения полей сначала сгенерируйте новую погоду. Старые записи «Колесо Судьбы — Генератор погоды» автоматически не переносятся.

## Проверка перед игрой

В тестовом мире проверьте: открытие всех пяти вкладок; Высшие эльфы → Воин тени/Мастер меча; Огры → Табунщик носорожцев; имена обоих полов; полный и отдельный пакеты; месячную погоду; копирование всей таблицы; видимость сообщений в чате; создание журнала; добавление биографии к тестовому персонажу с уже заполненной биографией.

Автотесты запускаются без установки зависимостей:

```powershell
npm test
```

Погода сверяется с 126 полными отчётами исходного Python-движка; дополнительно проверяются 720 комбинаций климата, месяца и режима ночного броска.

## GitHub и выпуск

Подробная инструкция находится в [GITHUB-INSTALL-RU.md](GITHUB-INSTALL-RU.md). Публиковать нужно содержимое этой папки как корень репозитория. GitHub Actions собирает архив и манифест версии `v0.2.0`; URL репозитория определяется автоматически. Для локальной установки URL не нужен.

Версия 0.2.0: кириллические имена всех народов, региональные человеческие наборы из Kurufin и полного предоставленного списка кислевитов; названия «гном»/«карлик»; общий погодный журнал с отдельными страницами по месяцу и году. Подробнее об источниках и вычитке — [NAMES-RU.md](NAMES-RU.md).

Версия 0.1.1: кнопки генерации с тёмно-красным фоном и двойной золотой рамкой; системные шрифты WFRP Caslon Antique/Caslon Pro; усиленные заголовки; красный полужирный текст проявившегося проклятия Азуриана. Шрифты берутся из установленной системы, без копирования файлов шрифтов в модуль.

Версия 0.1.2: минимальная версия Foundry снижена с 14 до 13, минимальная версия WFRP4e — с 10.1.2 до 9.6.0. Поле `system.details.biography.value`, используемое модулем, присутствует в обеих ветках системы. Используемые ApplicationV2, HandlebarsApplicationMixin и DialogV2 доступны в Foundry 13 и 14. Порог `verified` Foundry оставлен на непосредственно проверенной 14.369; ограничения сверху на версию системы WFRP4e нет. Ссылки обновлены на переименованный репозиторий.

## Структура

`module.json` — манифест; `scripts/` — интеграция и генераторы; `templates/` — Handlebars; `styles/` — стили только окна модуля; `data/` — таблицы; `lang/` — подписи настроек; `tests/` — проверки; `tools/release.mjs` — сборка ZIP; `.github/workflows/` — выпуск GitHub.

Инструменты `tools/export-*.py` и `export-careers.cjs` сохраняют происхождение переноса; для их повторного запуска нужны исходные desktop-файлы в родительской папке. Для обычной разработки и выпуска они не требуются.

Сведения об источниках и правах — в [NOTICE.md](NOTICE.md).
