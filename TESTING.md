# Проверка версии 0.1.0

Целевая установка: Foundry VTT 14.369, WFRP4e 10.1.2. Дата проверки: 26 октября 2026 года.

## Выполнено

- 12 автоматических тестов: 144 карьеры и фильтрация народов; имена и предыстории шести народов для обоих полов; 100 результатов проклятия; все 720 сочетаний климата, месяца и ночного режима; 126 полных контрольных отчётов исходного Python-движка; права на персонажей; дополнение биографии; видимость чата; приватность журнала; копирование строк/столбцов погоды; отсутствие эльфийских предупреждений у других народов.
- Окно `ApplicationV2` и Handlebars-шаблон реально отрисованы через установленный клиентский API Foundry, в отдельном браузерном контексте на `localhost:30000/setup`. В этом контексте пользователь, настройки и коллекция персонажей подставлены для проверки интерфейса; существующий игровой мир не запускался и не изменялся.
- Проверены переключение всех пяти вкладок, 144 строки реестра, генерация предыстории, имени и месячной таблицы погоды. Визуально проверены предыстория и погода. Необработанных ошибок JavaScript в этой проверке нет.
- ZIP проверен на корректность CRC и распаковки; структура содержит манифест в корне, 15 файлов, без изображений, музыки, PDF, Python и EXE. Размер распакованного пакета около 164 КиБ.
- Проверена сборка с заданным `owner/repository`: внешний манифест совпадает с манифестом внутри ZIP, адрес загрузки содержит соответствующий тег версии.
- Пакет установлен в пользовательскую `Data/modules/wfrp4e-wheel-of-destiny`.

## Остаётся проверить пользователю в тестовом мире

После перезапуска Foundry включить модуль в Manage Modules. Проверить отправку настоящего сообщения в чат, создание настоящей записи журнала, вставку в биографию тестового персонажа и отображение с остальными активными модулями. Эти операции проверены автоматически через контракты API, но не выполнялись над документами существующего мира.

Публикация на GitHub не выполнялась: подготовлены исходники, инструкция и workflow для аккаунта владельца. Публичный Manifest URL появится после первого GitHub Release.
